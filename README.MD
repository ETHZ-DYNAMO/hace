# HACE

HACE is an open-source and HLS-tool-agnostic framework that, from an HLS-produced register-transfer level (RTL) circuit netlist, reverse-engineers the control data flow graph (CDFG) of the originating software code. This CDFG can be used for debugging and exploration purposes (e.g., to investigate the intrinsic steps of an HLS compiler) as well as for comparing different HLS solutions (e.g., by using a CDFG of one HLS compiler as a starting point for another).
